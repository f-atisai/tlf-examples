## Approach & Principles

My work is guided by the following principles:

- **Structure over complexity**  
  Clear, well-organized outputs that support efficient review  

- **Reusability over repetition**  
  Solutions designed to scale across studies  

- **Clarity over cleverness**  
  Code and outputs that are easy to understand and validate  

- **Workflow alignment**  
  Solutions built with real clinical processes in mind  

- **Efficiency through automation**  
  Reducing manual effort where repeatable patterns exist
